# ORVENTO
<img width="1440" height="5198" alt="Desktop - 1" src="https://github.com/user-attachments/assets/d1b31643-0bec-4793-870e-013d3d3f17dc" />


ORVENTO is a modern and responsive event management landing page built with React and Vite. The project is designed to provide an engaging platform for promoting events, showcasing services, and delivering a seamless user experience across all devices.

## Features

- Responsive and modern user interface
- Clean and intuitive design
- Event showcase section
- Hero section with call-to-action
- About section
- Services section
- Contact section
- Optimized for desktop, tablet, and mobile devices
- Fast development with Vite

## Tech Stack

- React
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3

## Installation

Clone the repository:

```bash
git clone https://github.com/vishnuponoli21/ORVENTO.git
```

Navigate to the project directory:

```bash
cd ORVENTO
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```

## Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
